##### Installation
```sh
# Install rustup version management tool
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Update rust installation
rustup update

# # Show installed toolchains
# rustup show

# # Install toolchain
# rustup toolchain install 

# # Set default toolchain
# rustup default 
```
